🌱 Mi Huerto

Mi Huerto es una aplicación web y móvil orientada al monitoreo y gestión de huertos urbanos. El proyecto busca centralizar el seguimiento de plantas, visualizar información del huerto y facilitar la interacción del usuario mediante notificaciones y herramientas inteligentes.

🚧 Proyecto personal en desarrollo

🎯 Objetivo

Desarrollar una solución que permita a los usuarios gestionar sus plantas y consultar información de su huerto desde una aplicación web y móvil, integrando servicios modernos de backend, notificaciones y herramientas de automatización.

✨ Funcionalidades
🔐 Autenticación de usuarios.
🌱 Gestión y registro de plantas.
📊 Dashboard para visualizar información del huerto.
🔔 Sistema de alertas y notificaciones.
🤖 Chatbot con IA para asistencia al usuario.
☁️ Almacenamiento y gestión de datos mediante Supabase.
⚡ Supabase Edge Functions para lógica del backend.
💳 Integración con Stripe para funcionalidades relacionadas con suscripciones.
📱 Aplicación compatible con dispositivos móviles mediante Capacitor.
